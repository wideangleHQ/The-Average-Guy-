# Admin — Events

**Status: planned.** Admins manage event content where CMS functionality is included
(FR-EVT-005).

Event fields (per SRS §5.3 and the extended field list in
[AI development rules](../development/ai-development.md)): title, slug, short
description, full description, start/end date-time, location, cover image, category,
tags, registration URL/label, capacity, organizer, CTA, status, featured flag, and
event moments (media, caption, display order).

Event registration is implemented **only if separately approved** (FR-EVT-004,
SRS §13).
