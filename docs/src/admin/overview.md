# Admin Overview

**Status: planned, not implemented.** The admin dashboard is the content management
layer, built on the [Backend API](../backend/api.md) admin namespace.

## Candidate Areas

```text
Overview  Events  Communities  Media  Menu  Products  Regulars  Locations
Settings  Audit Logs
```

Not every module must be implemented immediately — features follow documented
requirements (see [Requirements](../project/requirements.md)), not a fixed roadmap.

## Rule

CMS fields, publishing workflow, and permissions must be finalized before admin
development begins (SRS §6). See [Permissions](permissions.md) for the access model.
