# Accessibility

Per NFR-003 and `DESIGN.md` §41.

## Requirements

- Strong text contrast.
- Visible focus states.
- Keyboard navigation.
- Accessible buttons and form labels.
- Meaningful image alt text.
- Touch-friendly controls.
- `prefers-reduced-motion` support (see [Animation](../design/animation.md)).

## Rule

**Gold must never be the only indicator of state** — pair it with another visual cue
(icon, weight, underline) for active/selected/error states.
