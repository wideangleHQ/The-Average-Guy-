# The Average Guy

Premium community-centric café website. Central idea: **"We are building a community."**

## Current Phase

Frontend environment & architecture setup only. **UI implementation has not started.**

## Stack

- **Frontend:** Next.js (`apps/web`) — implemented
- **Backend:** NestJS (`apps/api`) — planned, not yet initialized
- **Database:** PostgreSQL — planned

## Structure

```
apps/
├── web/   Next.js frontend
└── api/   empty placeholder for the future backend
docs/
```

## Development

```bash
npm install
npm run dev --workspace=web
```
